# Workout Tracker

Web application for tracking workouts as events.
Users can log workouts, categorize them by type, add tags, and view aggregated statistics over time.

## Scope
- User authentication
- Workout CRUD
- Workout types (categories)
- Tags and filtering
- Dashboard with aggregated metrics

## Tech stack (planned)
- FastAPI (backend API)
- SQLite (database)
- Streamlit (demo UI)
